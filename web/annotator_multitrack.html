Load a video and one track per person

Each track needs an IMU .parquet file (columns t_sec, ax, ay, az, plus optional gx, gy, gz). Optionally add a results JSON to edit, or a workout plan to auto-generate a starting timeline; or leave it empty to label from scratch. Everything stays in your browser — nothing is uploaded.

Tracks (one per person)

Sync sensors to the video

For each person, scrub to any frame where their watch timer is readable, type the value it shows, and press Set from this frame. A watch displays each value for a whole second, so a half-second is added automatically to compensate — leaving about ±0.5s of residual error. If you need it tighter, switch the dropdown to the flip-frame method. People can show their watches at different moments; each track is set independently. Or skip and label in video time.
